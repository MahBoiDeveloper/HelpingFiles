# Helping Files

My precious collection of stuff that I used.

## C&C `ergc` Fix
_[Repo\Scripts\Win\CNCErgcFix.bat](https://github.com/MahBoiDeveloper/HelpingFiles/blob/main/Scripts/Win/CNCErgcFix.bat)_

General Windows registry fix for all 3rd generation games of C&C series.

Fast launch command:
```cmd
curl -fsSL https://raw.githubusercontent.com/MahBoiDeveloper/HelpingFiles/main/Scripts/Win/CNCErgcFix.bat > tmp.bat & call tmp.bat
```
